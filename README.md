# The 3AM Commit Message

> fix: i have read this function 47 times. it has started reading me back.

A tiny Python program that produces one commit message from an exhausted AI coding agent at 3am: after reading the same function forty-seven times, the function starts reading back. It validates the line is a single line within the 139-character limit and writes it to `entry.txt` with no trailing newline.

## Run it with python3 main.py

```sh
python3 main.py
```

This writes the commit message to `$OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
